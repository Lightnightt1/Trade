# TradeGlass — النسخة المرتبطة بـ Supabase

**رابط تطبيقك:** https://nizarkhalid2.github.io/Trade/

**ما تم تجهيزه:** ملف `config.js` يحتوي رابط مشروعك و**المفتاح العام فقط**. توجد واجهة تسجيل حساب بالبريد وكلمة مرور، وإضافة/تعديل/حذف الصفقات، وتقويم أحمر وأخضر، وحفظ محلي احتياطي.

## قبل تفعيل المزامنة (ضروري)

1. افتح مشروعك في https://supabase.com/dashboard → **SQL Editor** → **New query**. انسخ كامل محتوى `schema.sql` واضغط **Run**. هذا ينشئ جدول `public.trade_entries` ويُفعّل سياسات **Row Level Security** التي تمنع المستخدمين من قراءة صفقات الآخرين.
2. اذهب **Authentication → URL Configuration**. ضع **Site URL**: `https://nizarkhalid2.github.io/Trade/` وأضف نفس الرابط في **Redirect URLs**.
3. في **Authentication → Providers → Email** تأكد من السماح بحسابات البريد وكلمات المرور. إذا طلب تأكيد البريد، افتح الرسالة وأكّد البريد ثم سجّل الدخول.
4. ادخل مستودع `https://github.com/nizarkhalid2/Trade` → **Add file → Upload files** وارفع **جميع الملفات من داخل هذا المجلد مباشرة** إلى جذر المستودع، واختر استبدال الملفات الحالية. اضغط **Commit changes**.
5. افتح `https://nizarkhalid2.github.io/Trade/` بعد اكتمال نشر GitHub Pages. اضغط **حسابي → إنشاء حساب**، ثم سجّل الدخول وأضف صفقة.
6. افتح الرابط من الهاتف الثاني وسجّل **بنفس الحساب**. انقر زر تحديث البيانات إذا لزم الأمر.

**إذا كانت لديك صفقات قديمة محفوظة محليًا:** بعد تسجيل الدخول اختر **الإعدادات → نقل للسحابة**. قبل النقل صدّر ملف CSV احتياطيًا، ولا تُكرر استيراد الصفقات إذا حدث خطأ في منتصف العملية، لتجنب تكرارها.

**تنبيه:** ربط المفاتيح داخل الملفات لا يعني أن قاعدة البيانات أُنشئت أو أن عملية الحفظ السحابي اختُبرت فعليًا. لن تعمل المزامنة إلا بعد تنفيذ `schema.sql` وتسجيل الدخول. إذا ظهر شريط «خطأ في المزامنة» فتأكد من قاعدة البيانات وRLS، واتصال الإنترنت.

**الأمان:** `sb_publishable_...` مفتاح عام يسمح بوضعه في كود المتصفح، لكنه ليس بديلًا عن RLS. لا تنسخ أبدًا مفاتيح `sb_secret_...` أو `service_role`، ولا كلمة مرورك إلى GitHub.
