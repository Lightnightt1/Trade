# TradeGlass — دفتر التداول ⚫

تطبيق ويب قابل للتثبيت (PWA) على الآيفون والأندرويد والكمبيوتر. التقويم يعطي اللون الأخضر للأيام ذات صافي الربح الموجب، والأحمر لصافي الخسارة السالب، والمحايد إذا كان الصافي صفرًا. إذا عندك أكثر من صفقة في اليوم تُجمع نتائجها تلقائيًا.

## ماذا يعمل الآن؟
- إضافة صفقات مع التاريخ والأصل والشراء/البيع ومبلغ الربح أو الخسارة والملاحظات.
- تعديل الصفقة وحذفها من أي يوم، وعرض صافي اليوم على التقويم.
- إحصائيات الأرباح والخسائر، الأيام الرابحة، نسبة الصفقات الرابحة، وأداء الشهر.
- وضع محلي يخزن البيانات على **هذا المتصفح فقط** حتى قبل إعداد الحساب.
- حساب شخصي مع بريد وكلمة مرور وحفظ في Supabase؛ البيانات تُزامن عند فتح التطبيق على جهاز آخر بالحساب نفسه وعند العودة للتطبيق.
- تصدير ملف CSV لكل الصفقات، ونقل الصفقات المحلية إلى الحساب السحابي.
- تثبيت من المتصفح إلى الشاشة الرئيسية (بعد الاستضافة عبر HTTPS).

## لتفعيل المزامنة بين الهواتف (إعداد مرة واحدة)

1. أنشئ مشروعًا مجانيًا أو مدفوعًا من https://supabase.com/dashboard.
2. افتح **SQL Editor** في المشروع، والصق وشغّل محتوى `schema.sql` لإنشاء قاعدة البيانات وسياسات الأمان RLS.
3. من **Project Settings → API / Data API** انسخ **Project URL** والمفتاح العام **Publishable key** (إذا واجهتك واجهة قديمة قد يسمى `anon` / `public`). **لا تستخدم مطلقًا secret أو service_role key**.
4. افتح `config.js` واستبدل القيم الفارغة، مثل:

   ```javascript
   window.TRADEGLASS_CONFIG = {
     supabaseUrl: "https://YOUR-PROJECT.supabase.co",
     supabasePublishableKey: "YOUR_PUBLIC_PUBLISHABLE_KEY"
   };
   ```

5. من **Authentication → Providers → Email** فعّل تسجيل البريد. إن كانت خاصية تأكيد البريد مفعّلة، سيحتاج المستخدم إلى الضغط على رسالة التأكيد قبل الدخول. أضف رابط موقعك المنشور إلى **Authentication → URL Configuration → Site URL / Redirect URLs** لكي تعمل روابط المصادقة.
6. انشر ملفات المجلد نفسها على استضافة ثابتة تدعم HTTPS مثل **Netlify Drop** أو GitHub Pages أو Cloudflare Pages. في Netlify يمكن رفع مجلد `TradeGlass` كاملًا عبر https://app.netlify.com/drop (تحتاج حسابًا).
7. افتح الرابط نفسه من جهازك أو من جهاز آخر، سجّل بحساب البريد وكلمة المرور **نفسهما**. سيظهر شريط الحالة «متصل بالسحابة» وتظهر سجلاتك.
8. إذا سجلت بيانات قبل تفعيل الحساب، افتح **الإعدادات → نقل للسحابة** بعد تسجيل الدخول. يتم نسخها ثم إزالة النسخة المحلية عند النجاح.

### تجربة على الكمبيوتر دون استضافة

افتح مجلد التطبيق في الطرفية ونفّذ `python -m http.server 8000`، ثم افتح `http://localhost:8000`. يعمل الوضع المحلي مباشرة دون Supabase. تتطلب المزامنة الاتصال بالإنترنت وربط Supabase وتكون الاستضافة عبر HTTPS هي الخيار الأفضل للهواتف.

### إضافة التطبيق لشاشة الآيفون

بعد نشره عبر HTTPS: افتح الرابط في Safari ← مشاركة ← **إضافة إلى الشاشة الرئيسية**. أجهزة أندرويد: من قائمة المتصفح اختر **Install app** أو **Add to Home screen**.

## ملاحظات مهمة

- لا توجد صفقات حقيقية ولا بيانات مفبركة عند فتح التطبيق لأول مرة. أضف بياناتك بنفسك.
- الربح والخسارة في التقويم يحسبان بالدولار الأمريكي ويعكسان ما تُدخله يدويًا؛ **ليس له اتصال بحساب MT5 أو Exness أو XTB**.
- تأكد من خدمة الإيميل وحدود استخدام خطة Supabase و Netlify المختارة قبل الاعتماد عليها على نطاق واسع.
- لا تنشر أبدًا مفتاح `service_role` ولا كلمة مرورك في ملفات التطبيق؛ مفتاح `publishable` مصمم للاستخدام داخل المتصفح، والحماية تعتمد على سياسات RLS في `schema.sql`.
- مصدر البيانات السحابي خاص بكل حساب: نظام RLS يمنع الحسابات الأخرى من قراءة أو تعديل صفقاتك.
- بيانات الوضع المحلي تعتمد على تخزين المتصفح، لذلك لا تمسح بيانات الموقع قبل نقلها للسحابة أو تصديرها.

تصميم التطبيق: RTL عربي، أسود وأبيض ورصاصي مع تأثير Glassmorphism زجاجي متجاوب. الأخضر للربح والأحمر للخسارة فقط. يمكن تعديل تدرجات التصميم من `theme-monochrome.css`.
